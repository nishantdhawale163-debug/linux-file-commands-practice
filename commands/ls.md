# ls Command

## Description
The `ls` command lists files and directories in Linux.

## Syntax
ls [options] [directory]

## Examples

List files in the current directory

ls

Detailed list

ls -l

Show hidden files

ls -a

Human readable file sizes

ls -lh

## Practice

mkdir test_folder
cd test_folder
touch file1 file2 file3
ls
ls -l
ls -a
